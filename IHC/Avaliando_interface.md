# Atividade: Análise de Interface

## Objetivo

Realizar uma análise de um site ou aplicativo com base nos conceitos de **Interface e Interação**, **Usabilidade**, **Acessibilidade**, **Ergonomia**, **Responsividade** e **ISO 9241**.

---

## Formação dos Grupos

- Formem grupos de **3 a 4 alunos**.
- Cada grupo deve escolher **um site ou aplicativo** para análise (escolha livre).

---

## Análise da Interface

Avaliem a interface escolhida considerando os seguintes aspectos:

### Interface e Interação
- Identificar elementos de **entrada**:
  - Cliques
  - Toques
  - Comandos de voz (quando disponíveis)
- Identificar elementos de **saída**:
  - Feedback visual
  - Feedback sonoro

### Usabilidade
- Facilidade de uso.
- Clareza das funções.
- Prevenção de erros.

### Acessibilidade
- Contraste de cores.
- Legendas.
- Compatibilidade com leitores de tela.
- Outros recursos de inclusão.

### Ergonomia
- Conforto visual.
- Organização das informações.
- Distribuição dos elementos na interface.

### Responsividade
- Verificar a adaptação da interface em:
  - 💻 Desktop
  - 📱 Celular
  - 📲 Tablet

### ISO 9241
Verificar se a interface segue os princípios ergonômicos definidos pela norma **ISO 9241**.

---

## Registro da Análise

Documentem em um arquivo compartilhado:

### Pontos Fortes
- Liste os aspectos positivos encontrados.

### Pontos Fracos
- Liste os aspectos que podem ser melhorados.

---

## Discussão em Grupo (15 minutos)

Cada grupo deverá preparar uma síntese contendo:

- ✅ **1 ponto positivo** da interface analisada.
- ❌ **1 ponto negativo** da interface analisada.

Após isso, compartilhem os resultados com a turma para comparação e debate.

---

## Apresentação (15 minutos)

Cada grupo terá **até 3 minutos** para apresentar sua análise.

---

# Regras da Atividade

- Todos os integrantes devem participar da análise e da discussão.
- O objetivo é aprender com exemplos reais, e não apenas criticar.
- Utilizem linguagem clara e objetiva durante a apresentação.
- Relacionem sempre as observações aos conceitos estudados:
  - Usabilidade
  - Acessibilidade
  - Ergonomia
  - Responsividade
