# Desenvolvimento de Interface (ADS)

## Ementa da Disciplina

- Introdução à Interação Humano-Computador (IHC).
- Conceitos e elementos da prática do projeto de interação:
  - Usabilidade
  - Acessibilidade
  - Ergonomia
  - Responsividade
- Modelos, padrões e normas de usabilidade e acessibilidade.
- Desenvolvimento de interfaces web interativas com foco nas tecnologias fundamentais:
  - HTML
  - CSS
  - JavaScript
- Projeto, prototipação e desenvolvimento de interfaces estáticas e dinâmicas centradas no usuário, aplicando os conceitos e princípios de UX/UI.
- Introdução aos principais frameworks e bibliotecas JavaScript no contexto de UX/UI.
