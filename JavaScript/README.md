## Sobre o projeto

Este repositório reúne as atividades práticas desenvolvidas durante a disciplina **Desenvolvimento de Interface**, com o objetivo de aplicar os conhecimentos adquiridos em sala de aula por meio de exercícios e pequenos projetos.

## Aula 01 — Introdução ao JavaScript

### Conteúdos estudados

- Introdução ao JavaScript.
- Variáveis: `let` e `const`.
- Tipos de dados.
- Operadores aritméticos.
- Operadores de atribuição.
- Operadores de comparação.
- Operadores lógicos.

### Atividades desenvolvidas

- Cadastro simples de usuário.
- Calculadora de operações matemáticas.
- Calculadora de média de notas.

### Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
- Visual Studio Code

### Como executar

1. Faça o download ou clone este repositório.
2. Abra a pasta da aula.
3. Execute o arquivo `index.html` no navegador.

## Organização das aulas

A cada aula, o estudante acrescentará um novo projeto ou atividade ao mesmo repositório, aplicando os conhecimentos adquiridos durante a disciplina.

### Aula 1 — Fundamentos JavaScript

- Variáveis.
- Tipos de dados.
- Operadores.

### Aula 2 — Condicionais e DOM

- Interfaces que recebem dados.
- Estruturas condicionais.
- Interfaces que tomam decisões.

### Aula 3 — Estruturas de repetição e funções

- Estruturas de repetição.
- Criação de funções.
- Automatização e reutilização de código.

### Aula 4 — Eventos e manipulação do DOM

- Eventos em JavaScript.
- Manipulação do DOM.
- Interatividade nas páginas web.

### Aulas seguintes — Projetos integradores

- Desenvolvimento de interfaces completas.
- Integração dos conhecimentos estudados.
- Criação de projetos práticos.
