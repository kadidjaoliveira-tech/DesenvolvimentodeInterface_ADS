# Conclusão do Módulo JavaScript: Projeto Calculadora de Média

Olá, estudantes!

Estamos concluindo o **Módulo JavaScript**, composto por três aulas práticas e complementares. Ao final desse percurso, vocês deverão produzir uma **aplicação web funcional**, integrando **HTML, CSS e JavaScript**.

## Evolução do projeto

1. **Aula 1 — Variáveis, tipos e operadores:** aprendemos a armazenar o nome e as notas, realizar cálculos e apresentar resultados.
2. **Aula 2 — Condicionais, repetições e funções:** organizamos o cálculo da média em uma função e acrescentamos a classificação do estudante em **Aprovado**, **Recuperação** ou **Reprovado**.
3. **Aula 3 — DOM, eventos e validação:** conectamos a lógica aos campos da página, ao botão de cálculo e à área de apresentação do resultado.

## Os códigos são complementares?

Sim. O projeto da Aula 3 reaproveita diretamente os conhecimentos desenvolvidos nas aulas anteriores:

- **Variáveis e tipos:** armazenar o nome e as notas;
- **Operadores:** calcular a média;
- **Comparações e condicionais:** verificar e classificar o resultado;
- **Funções:** organizar o cálculo;
- **DOM:** acessar os elementos da página;
- **Eventos:** executar o programa ao clicar no botão;
- **Validação:** impedir campos vazios ou notas incorretas.

Os exercícios intermediários das Aulas 1 e 2 são independentes e não precisam ser reunidos em um único arquivo. Eles foram desenvolvidos para exercitar competências específicas.

O código cumulativo é o da **Calculadora de Média**, que começou como um cálculo simples no console, recebeu funções e decisões e, finalmente, tornou-se uma aplicação web interativa.

## Para concluir o módulo

Finalize a Calculadora de Média verificando se a aplicação:

- [ ] Recebe o nome do estudante;
- [ ] Recebe três notas;
- [ ] Calcula corretamente a média;
- [ ] Classifica o resultado;
- [ ] Valida campos vazios;
- [ ] Rejeita notas fora do intervalo de 0 a 10;
- [ ] Apresenta mensagens claras na própria página;
- [ ] Utiliza arquivos separados para HTML, CSS e JavaScript;
- [ ] Funciona sem erros no console do navegador;
- [ ] Possui o registro dos testes realizados.

## Testes obrigatórios

Antes da entrega, execute e registre pelo menos:

1. Um caso de **aprovação**;
2. Um caso de **recuperação**;
3. Um caso de **reprovação**;
4. Um caso com **campos vazios**;
5. Um caso com **dados inválidos**.

A conclusão deste projeto demonstrará que vocês compreenderam como integrar estrutura, apresentação, lógica e interação em uma aplicação web.
